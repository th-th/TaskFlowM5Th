TaskFlow – Aplicación de Gestión de Tareas en JavaScript

TaskFlow es una aplicación web interactiva desarrollada en JavaScript moderno (ES6+) que permite gestionar tareas de manera simple y eficiente. El proyecto aplica conceptos de programación orientada a objetos, manipulación del DOM, eventos, asincronía y consumo de APIs.

Características

- Crear tareas
- Editar o cambiar el estado de las tareas
- Eliminar tareas
- Interacción dinámica mediante eventos del DOM
- Consumo de una API externa para obtener datos del clima
